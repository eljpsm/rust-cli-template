# renameme

A placeholder command line tool.

## Install

```bash
# With cargo:
cargo install --git https://github.com/eljpsm/renameme

# With nix:
nix run github:eljpsm/renameme

# Or from a checkout:
make install
```

## Usage

```bash
# Print a greeting.
renameme greet
renameme greet --shout crab

# Count the lines in a file.
renameme count notes.txt
```
